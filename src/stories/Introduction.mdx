# Ebuyer component library

Ebuyer is a storefront built with Next.js, [MUI](https://mui.com) (Material UI v9) themed with CSS
variables, Tailwind CSS v4 for layout utilities, Redux Toolkit and D3.

Every story renders inside the Ebuyer MUI theme and an isolated Redux store preloaded with sample
orders. Use the **Theme** toolbar to switch light and dark mode.

- **Product** – product card, price, quantity stepper, wishlist and add-to-bag buttons
- **Cart** – order summary with promo codes and the free-delivery progress bar
- **Checkout** – the live card preview that flips for the CVC
- **Charts** – D3 price histogram with brush, price history, rating breakdown and spending charts
